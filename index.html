§ 03 Also

Infrastructure and operations

  • Search Console and indexing. Currently resolving a canonical tag and sitemap URL conflict that has kept nine service pages unindexed for over a month.
  • Local search diagnosis. Determined that distance from the verified address — not category or services configuration — was the real constraint on map pack visibility in outer towns.
  • Conversion tracking recovery. A site rebuild wiped the phone snippet; fixed by hardcoding the tag and snippet into static HTML so a future rebuild can't silently remove them again.
  • UTM parameters on Google Business Profile links, to stop profile traffic being misattributed to organic.
  • DNS. Diagnosed and fixed a stale www A record via a Cloudflare redirect rule.
  • Continuity. Set up a GitHub organization, Cloudflare administrator access for the owner, and Google Workspace email — so the business isn't dependent on me to keep operating.
  • In progress. Call-capture automation using OpenPhone, structured extraction from call transcripts, and Cloudflare Workers as the glue layer.
